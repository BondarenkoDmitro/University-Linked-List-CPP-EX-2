# cpp-oop-classes-EX-2

## Описание задачи (Варіант 3)

**Постановка:**
Створити динамічний клас `University`, що базується на зв'язному списку. Кожний елемент списку (вузол) містить інформацію про факультет:
- назва факультету;
- прізвище декана;
- кількість груп на факультеті;
- загальна кількість студентів у цих групах.

Клас повинен реалізувати операції:
- `add_group()` - додавання групи;
- `del_group()` - видалення групи;
- `calc_stud()` - підрахунок кількості студентів на факультеті.

---

## Цель работы

Реализовать ООП-модель университета на основе **односвязного списка**, научиться:
- работать с динамической памятью в C++;
- проектировать класс с инкапсуляцией структуры данных;
- корректно изменять агрегированные данные (количество групп и студентов);
- обрабатывать граничные случаи (пустой список, несуществующий факультет, удаление последней группы и т.д.).

---

## Что моделирует класс `University`

`University` хранит набор факультетов. Каждый факультет - это узел связного списка.

### Логическая структура узла

- `facultyName` - название факультета (`std::string`)
- `deanSurname` - фамилия декана (`std::string`)
- `groupCount` - число групп на факультете (`int`)
- `studentsTotal` - суммарное число студентов по всем группам факультета (`int`)
- `next` - указатель на следующий узел списка

### Почему связный список

Связный список подходит, когда:
- количество факультетов заранее неизвестно;
- важны частые вставки/удаления без полного перераспределения памяти;
- нужно явно потренироваться в работе с указателями и динамической памятью.

---

## Контракт операций

### `add_group(facultyName, deanSurname, groupStudents)`

**Назначение:** добавить новую группу на факультет.

**Ожидаемое поведение:**
1. Если факультет уже есть:
   - `groupCount += 1`
   - `studentsTotal += groupStudents`
2. Если факультета нет:
   - создать новый узел;
   - заполнить название факультета и фамилию декана;
   - установить `groupCount = 1`;
   - установить `studentsTotal = groupStudents`;
   - добавить узел в список.

**Проверки входных данных:**
- `groupStudents` не должен быть отрицательным;
- `facultyName` не должен быть пустой строкой.

### `del_group(facultyName, groupStudents)`

**Назначение:** удалить одну группу с указанным количеством студентов с факультета.

**Ожидаемое поведение:**
1. Найти факультет по `facultyName`.
2. Если факультет не найден - вернуть ошибку/`false`.
3. Если найден:
   - уменьшить `groupCount` на 1;
   - уменьшить `studentsTotal` на `groupStudents`;
   - не допускать ухода `studentsTotal` в отрицательное значение.
4. Если после удаления `groupCount == 0`:
   - удалить узел факультета из списка полностью;
   - корректно перенастроить указатели.

### `calc_stud(facultyName)`

**Назначение:** вернуть общее число студентов на факультете.

**Ожидаемое поведение:**
- при наличии факультета вернуть `studentsTotal`;
- при отсутствии факультета вернуть специальное значение (например `-1`) или выбросить исключение - в зависимости от выбранного контракта.

## Рекомендуемый интерфейс класса

```cpp
class University {
public:
    University();
    ~University();

    bool add_group(const std::string& facultyName,
                   const std::string& deanSurname,
                   int groupStudents);

    bool del_group(const std::string& facultyName,
                   int groupStudents);

    int calc_stud(const std::string& facultyName) const;

    void print() const;

private:
    struct Node {
        std::string facultyName;
        std::string deanSurname;
        int groupCount;
        int studentsTotal;
        Node* next;
    };

    Node* head;

    Node* findFaculty(const std::string& facultyName) const;
    void clear();
};
```

## Алгоритмическая сложность

Для односвязного списка (без доп. индексов):
- поиск факультета: `O(n)`
- `add_group()`: `O(n)` (из-за поиска)
- `del_group()`: `O(n)`
- `calc_stud()`: `O(n)`

Память: `O(n)`, где `n` - количество факультетов.

---

## Типичные ошибки и как их избежать

1. **Утечки памяти**
   - обязательно реализовать деструктор, который удаляет все узлы.
2. **Потеря связности списка**
   - при удалении узла аккуратно обновлять `next` предыдущего узла.
3. **Неверная работа с головой списка (`head`)**
   - отдельная обработка случая, когда удаляется первый узел.
4. **Некорректные агрегаты**
   - после каждой операции проверять инварианты:
     - `groupCount >= 0`
     - `studentsTotal >= 0`
     - если `groupCount == 0`, узел факультета не должен оставаться в списке.

## Минимальные сценарии тестирования

1. Добавить первую группу на новый факультет.
2. Добавить вторую группу на тот же факультет.
3. Проверить `calc_stud()` после нескольких добавлений.
4. Удалить одну группу и проверить пересчёт студентов.
5. Удалить последнюю группу - убедиться, что факультет удалён из списка.
6. Вызвать операции для несуществующего факультета.
7. Проверить корректность работы на пустом списке.
