# University Management System (C++)

### Variant 3: Create a dynamic University class based on a linked list

Create a dynamic class University based on a linked list, where each list element contains information about faculties: faculty name, dean's surname, number of groups at the faculty, total number of students in groups.

The class must contain the following operations:

- `add_group()` – add a faculty;
- `del_group()` – delete a faculty;
- `calc_stud()` – count the number of students at a faculty.

#### Data Structure:

Each faculty node contains:
- Faculty name
- Dean's name
- Number of groups
- Total number of students

#### Additional Features:

- Display all faculties with complete information
- Interactive menu for managing faculties
- Input validation and error handling

# Система управления университетом (C++)

### Вариант 3: Создать динамический класс University на основе связного списка

Создать динамический класс University, что базируется на связном списке, где каждый элемент списка содержит информацию о факультетах: название факультета, фамилию декана, количество групп на факультете, общее количество студентов в группах.

Класс должен содержать следующие операции:

- `add_group()` – добавление факультета;
- `del_group()` – удаление факультета;
- `calc_stud()` – подсчет количества студентов на факультете.

#### Структура данных:

Каждый узел факультета содержит:
- Название факультета
- Фамилию декана
- Количество групп
- Общее количество студентов

#### Дополнительные возможности:

- Отображение всех факультетов с полной информацией
- Интерактивное меню для управления факультетами
- Валидация входных данных и обработка ошибок
